# Contributing / المساهمة

Thank you for contributing to the projects maintained by Ahmed Ibrahim.

1. Open an issue in the **specific repository** describing your use case, expected behavior, actual behavior, host version and a minimal reproducible example.
2. Before proposing code, read that project's README, `AGENTS.md` (if provided), license and tests.
3. Make a focused branch and pull request with a concise summary, screenshots (if UI changes), relevant tests, and any known limitations.
4. Do not add commercial GIS SDK binaries, private datasets, credentials, API keys, proprietary map tiles, personal monitoring records or unlicensed fonts/styles.
5. Respect the project-specific license. GIS results should state data source, CRS, units, NoData handling and validation evidence. Native Windows/ArcGIS/QGIS UI behavior must not be claimed from static source checks.
6. Contributors should be kind and constructive; Arabic and English are welcome.

**بالعربية:** افتح Issue داخل المستودع المختص، واكتب خطوات إعادة المشكلة وإصدار البرنامج وبيانات اختبار غير حساسة. أرفق التعديلات باختبارات موثقة، ولا تنشر بيانات شخصية أو ملفات تجارية غير مرخّصة. المشاريع التجريبية لا تُعد إصدارات إنتاجية.
