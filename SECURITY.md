# Security policy / سياسة الأمان

## Reporting a vulnerability

Please **do not disclose exploits, API keys, sensitive geospatial datasets, network monitoring histories or personal identifiers in public GitHub Issues**.

Use GitHub's **Private vulnerability reporting** if enabled for the affected repository. If it is not enabled, contact the maintainer at **ahmadibrahim.geo@gmail.com** with a minimal, sanitized report. Avoid attaching live credentials, private location traces or user data. Do not assume the email address implies encrypted delivery.

Include the affected repo/version, relevant environment, reproducibility summary and impact. Do not attempt exploitation against third-party services or real user data without explicit authorization.

## Support scope

Security fixes depend on maintainers' capacity; no guaranteed response or remediation SLA is offered. Repositories may be experimental and can rely on optional commercial GIS hosts, external data services and separately licensed components. Check the project-specific README, security policy and release notes. Contact maintainers before disclosing details publicly.

**بالعربية:** يرجى الإبلاغ بشكل خاص عن الثغرات وعدم نشر كلمات المرور أو مفاتيح API أو قواعد بيانات شخصية أو مواقع دقيقة في البلاغات العامة.
