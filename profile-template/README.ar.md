## مجالات العمل

- **نظم المعلومات الجغرافية:** ArcGIS Pro وArcMap وQGIS وArcPy وGDAL/PROJ.
- **المناخ والاستشعار عن بُعد:** البيانات المناخية ونماذج الارتفاعات الرقمية والاستيفاء والتحليل المكاني.
- **تطوير البرمجيات:** Python و.NET/WPF وJavaScript وCesiumJS ومعالجة KML/KMZ.
- **الجودة:** التوثيق، واختبار البرمجيات، وتتبع مصادر البيانات، والتحقق من النتائج.
