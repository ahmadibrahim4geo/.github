## Technical focus

**GIS and analysis:** ArcGIS Pro / ArcMap, QGIS, ArcPy, GDAL/PROJ, spatial data conversion and automation.

**Remote sensing and climate:** DEMs, climate datasets, weather-station analysis, interpolation and cartographic outputs.

**Application development:** Python, desktop GIS, .NET/WPF, JavaScript, CesiumJS, KML/KMZ and reproducible test workflows.
