# Support / الدعم

Open a question or bug report in the relevant project's **Issues** or **Discussions** tab.

When reporting a problem, provide: project name, version/commit, Windows/GIS host version if applicable, exact reproduction steps, expected/actual results, synthetic sample data, error excerpts (with credentials removed), and whether native UI tests were actually run.

For general project or collaboration enquiries: [ahmadibrahim.geo@gmail.com](mailto:ahmadibrahim.geo@gmail.com).

**بالعربية:** للدعم الفني، افتح بلاغًا داخل المشروع المناسب مع خطوات تكرار المشكلة وإصدار البرنامج وبيانات تجريبية خالية من المعلومات الخاصة. مساهمات البحث والتطوير والاختبارات العلمية مرحّب بها.
